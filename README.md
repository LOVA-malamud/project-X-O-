# Tic-Tac-Toe · Python Console Game

A small terminal game practicing board state, functions, move validation and a random computer opponent.

**Status:** learning project using Python's standard library.

## Play

From the repository root, run:

```bash
python3 'project X-0.py'
```

Follow the prompts to choose moves from 1–9; enter `q` at a move prompt to quit. The code tracks wins and ties across rounds. Read [the original source](project%20X-0.py) to follow board creation, winner checks and turn switching.

## Study the flow

Start with `create_board`, then `get_move`, `check_winner` and `play_game`. There are no third-party dependencies or automated tests. The documentation pass checks the source path and syntax; interactive gameplay is not revalidated.
